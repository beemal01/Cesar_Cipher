# Cesar_Cipher
The **Caesar Cipher** is a simple substitution cipher used for encryption. It works by shifting each letter in the plaintext by a fixed number of positions in the alphabet. For example, with a shift of 3, 'A' becomes 'D', 'B' becomes 'E', and so on.  

In Python, the Caesar cipher can be implemented using the `ord()` and `chr()` functions to manipulate character ASCII values. It can be used for both encryption and decryption by adjusting the shift direction. Though easy to implement, it is vulnerable to brute-force attacks due to its limited key space.
